# Quark 2 Docs

**Quark 2 Docs** is a child theme of Quark 2 that adds a documentation layout to Grav: a collapsible sidebar, the article, and an "On this page" table of contents.

This site is the theme's demo. Every page here is real documentation for the theme, and the pages themselves use the features they describe.

## Try it out

- **Expand and collapse** sections in the sidebar. The section you are reading stays open.
- Open any page *below* a section to see the **On this page** list on the right.
- **Resize the window.** On narrow screens the sidebar moves above the article.
- **Switch between light and dark mode** with the theme toggle in the header.

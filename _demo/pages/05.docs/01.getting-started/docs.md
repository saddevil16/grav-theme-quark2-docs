# Getting Started

Welcome to Quark 2 Docs, a documentation website built with Grav CMS.

This guide introduces the project, explains its requirements, and walks you through setting up your documentation environment.

Whether you are creating your first documentation website or maintaining an existing project, this section will help you get started.

### What You Will Learn

By the end of this guide, you will understand how to:

- Install and configure the documentation environment.
- Organize content into sections and nested pages.
- Customize the appearance of the documentation.
- Write documentation using Markdown.
- Maintain and deploy your website.

### Before You Begin

You should have basic familiarity with:

- Using a terminal or command prompt.
- Managing files and directories.
- Editing text files.
- Understanding basic HTML and CSS.

You do not need to be an expert in web development.

#### Configurations

#### Themes

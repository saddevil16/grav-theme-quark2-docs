# Quark 2 Docs

Quark 2 Docs is a documentation website template designed to make technical information easier to navigate and understand.

The project combines the flexibility of Grav CMS with a structured documentation layout.

### Key Features

#### Hierarchical Navigation

Organize documentation into sections, topics, and subtopics.

The navigation structure follows the content directory, allowing related pages to remain grouped together.

#### Table of Contents

Long documentation pages can display an **ON THIS PAGE** section.

This section provides links to headings within the current page, helping readers navigate lengthy content.

#### Customizable Appearance

Customize typography, spacing, colors, navigation, and other visual elements through theme settings and CSS.

#### Markdown Support

Write documentation using Markdown instead of manually creating HTML pages.

#### Lightweight Architecture

Grav stores content in files, making it possible to manage documentation using a text editor and version control.

### How It Works

The documentation website consists of three primary components.

| Component | Responsibility |
|---|---|
| Grav CMS | Manages pages, routing, and content. |
| Theme | Controls templates, navigation, and presentation. |
| Markdown | Defines the written content and document structure. |

These components work together to generate the final website.

### Project Goals

Quark 2 Docs aims to provide:

- Clear and consistent documentation.
- Predictable page hierarchy.
- Readable typography.
- Convenient navigation.
- Maintainable theme customization.

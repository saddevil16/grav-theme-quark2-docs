# Requirements

Before installing Quark 2 Docs, ensure that your environment supports Grav CMS.

The exact requirements depend on the Grav version and the plugins installed.

### Required Software

#### PHP

Grav requires a compatible PHP installation.

Check the requirements for the specific Grav release you intend to use, including its required PHP version and extensions.

To check your installed PHP version, run:

```bash
php -v
```

To inspect the installed PHP extensions, run:

```bash
php -m
```

#### Web Server
You can run Grav using a supported web server such as Apache or Nginx.

For local development, PHP's built-in web server can also be useful.

#### Composer
Composer is a PHP dependency manager.

Some Grav installations and development workflows use Composer to manage dependencies. Follow the installation instructions for your chosen Grav distribution.

### Recommended Development Tools

| Tool | Purpose |
| --- | --- |
| Git | Version control and change tracking. |
| Visual Studio Code | Editing Markdown, Twig, YAML, and CSS. |
| Browser developer tools | Inspecting layouts and debugging styles. |
| Terminal | Running commands and managing files. |

These tools are recommendations rather than mandatory dependencies.

### Verify Your Environment
Check the following before proceeding:
- PHP meets the requirements of your Grav version.
- Required PHP extensions are available.
- The web server can access the Grav directory.
- The relevant directories have appropriate permissions.
- Your browser supports the features used by the theme.

### Next Step
Once the environment is ready, proceed with the installation guide.

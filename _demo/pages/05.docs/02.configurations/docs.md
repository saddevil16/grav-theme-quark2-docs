# Configurations

This section explains how to customize the behavior and appearance of Quark 2 Docs.

Configuration options are divided into separate topics so that each area can be maintained independently.

### Available Topics

#### Site Settings

Learn about the main website configuration, including the site title, metadata, and general settings.

#### Theme Settings

Understand how theme configuration controls the layout and presentation of the documentation.

#### Navigation

Learn how page hierarchy, navigation labels, and sidebar organization work together.

#### Custom CSS

Customize typography, spacing, colors, and other visual elements without unnecessarily modifying theme templates.

#### Performance

Explore caching and other techniques that can improve page loading and website responsiveness.

### Configuration Principles

When customizing the website, follow these principles:

- Keep configuration separate from content.
- Prefer supported theme settings when available.
- Use custom CSS for presentation changes.
- Avoid editing core Grav files.
- Keep changes organized and documented.
- Test changes before deploying them.

### Where to Begin

If you are new to the project, start with Site Settings.

If you are already familiar with Grav, you may prefer to explore Theme Settings or Custom CSS directly.
